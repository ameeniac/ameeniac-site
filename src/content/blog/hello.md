I've been meaning to write for a while, and kept not doing it because the setup
always felt like the hard part. Pick a platform, pick a theme, sign up for
something with a monthly fee, then discover the export button doesn't quite work.

So this is deliberately boring underneath. Posts are Markdown files in a folder.
The site is static HTML. If I ever want to leave, I take the folder with me.

## What I expect to write about

Mostly work-adjacent things — service management, discovery and dependency
mapping, the gap between how a tool is demoed and how it behaves in a real
environment six months in. Some of it will be notes to my future self.

## The rules I'm giving myself

- Publish before it's polished.
- Short is fine. One idea per post is fine.
- No engagement metrics anywhere on this site.

That's it. Delete this post once there's something better on the front page.
